# DentaPremium — сайт стоматологии с онлайн-записью и оплатой

Премиальный сайт стоматологической клиники: лендинг, страницы врачей и услуг,
умная онлайн-запись («подберите за меня»), приём платежей через ЮKassa
(карта + СБП), управление записью пациентом по защищённой ссылке, уведомления
в Telegram и на email, CRM для администратора со статистикой и недельным
календарём, отзывы с модерацией и SEO-разметка schema.org.

## Стек

- **Next.js 16** (App Router, Server Actions, Turbopack) + **React 19** + **TypeScript**
- **Tailwind CSS 4**, иконки **lucide-react**, календарь **react-day-picker**
- **Prisma 7** + SQLite (драйвер better-sqlite3)
- **Zod** — валидация на сервере
- **ЮKassa** — оплата картой и по СБП
- **nodemailer** (любой SMTP) и **Telegram Bot API** — уведомления
- **bcryptjs** — хеширование пароля администратора
- **GitHub Actions** — CI: линт, сборка и smoke-тест страниц

## Дизайн-система

Тема **«Мята на графите»** — тёмная премиальная, токены и утилиты в `src/app/globals.css`:

- **Палитра**: графит `#05090b` с зелёным подтоном, мятный акцент `#3ce6bd`,
  шампанское золото `#e9c98d` для рейтингов, приглушённый текст `#8ca29b`
- **Типографика** (кириллица, next/font): дисплейный **Unbounded** для заголовков,
  курсивный **Cormorant** для акцентных слов, **Manrope** для текста
- **Утилиты**: `.btn-primary` / `.btn-ghost` (пилюли с градиентом и свечением),
  `.card` (стекло), `.chip` / `.chip-mint`, `.field` (инпуты), `.glow` (орбы фона),
  зерно-оверлей, бегущая строка, тёмная тема react-day-picker
- **Крупные узлы**: стеклянная шапка с пилюлей-навигацией и полноэкранным
  мобильным меню, hero с орбитальной композицией, бенто-сетки услуг и
  преимуществ, CTA-панель, футер с контактной строкой

## Возможности

**Публичная часть**

- Лендинг: hero с орбитальной композицией и статистикой, бегущая строка услуг,
  бенто-сетка услуг, преимущества, топ-врачи, этапы записи, отзывы, FAQ, CTA
- Страницы «Врачи» и «Услуги» с ценами и длительностью
- Отзывы: каждый попадает на сайт только после модерации в админке
- SEO: sitemap.xml, robots.txt, JSON-LD (Dentist + AggregateRating + FAQPage),
  динамическая OG-картинка (1200×630, кириллица), метаданные каждой страницы

**Онлайн-запись (`/book`)**

- Врач — опционально: режим **«Подберите за меня»** назначит свободного
  специалиста на выбранное время
- Слоты считает **сервер**: расписание врача (`Schedule`), длительность услуги,
  занятые записи, прошедшее время. Дефолт пн–сб 9:00–18:00, вс — выходной
- Создание записи в транзакции: автоназначение врача, проверка графика и
  пересечений — двойная бронь невозможна (SQLite сериализует запись)
- Оплата картой или СБП; после успеха — страница с деталями записи
- **Управление записью по защищённой ссылке** (`/booking/<token>`): статус,
  отмена, перенос, экспорт в календарь `.ics`. Токен — 256 бит, срок 90 дней

**Уведомления (бесплатные каналы)**

- Telegram админу: новая запись, оплата, отмена платежа
- Email пациенту (SMTP): подтверждение записи, оплата, напоминание за 24 часа
  (`/api/cron/reminders`, вызывается внешним cron с секретом)

**Админ-панель (`/admin`)**

- Дашборд: записи за сегодня, оплачено за месяц, быстрые действия
- **Недельный календарь** по врачам: записи в сетке, «+» в клетке — записать
  пациента вручную (приём по телефону)
- Ручная запись: выбор врача/услуги/слота из серверного расчёта
- Управление расписаниями врачей (интервалы по дням недели)
- Услуги: создание, редактирование цены/длительности, скрытие из записи
- Лента ближайших записей: принять, отменить, отметить оплату в клинике
- Модерация отзывов
- Экспорт записей в CSV (Excel-ready: `;` + BOM)

## Безопасность

- Сумма платежа берётся **из БД по записи** — клиент не может назначить свою цену
- Вебхук ЮKassa принимает запросы **только с IP-адресов ЮKassa**
  (карты сетей + IPv6 `2a02:5180::/32`) и **идемпотентен**: повторная доставка
  события не меняет запись второй раз (`ProcessedEvent`)
- Сессия администратора — подписанная HMAC-SHA256 cookie (`HttpOnly`),
  подделать значение из браузера нельзя
- Пароль админа: открытый в `ADMIN_PASSWORD` или **bcrypt-хеш** в
  `ADMIN_PASSWORD_HASH` (`npm run hash-password`); вход ограничен
  rate-limit'ом (5 попыток за 15 минут на IP)
- **Каждый админский Server Action проверяет сессию внутри** — вызов экшена
  без авторизации невозможен даже при подделке запроса
- Ссылка управления записью — случайный токен 256 бит, не угадывается
- Персональные данные (`dev.db`, `.env`) вне git

## Быстрый старт

```bash
npm install
cp .env.example .env          # заполнить ADMIN_PASSWORD и ключи ЮKassa
npm run db:push               # создать схему БД
npm run seed                  # демо-врачи, расписание, услуги, отзывы
npm run dev                   # http://localhost:3000
```

Админка: `/login` → пароль из `ADMIN_PASSWORD` → `/admin`.

Уведомления (необязательно): заполните `TG_BOT_TOKEN`/`TG_CHAT_ID` для Telegram
и `SMTP_*` для email — без них сайт работает, уведомления просто отключены.

Напоминания о приёмах: дёргайте раз в час любой бесплатный планировщик:

```bash
curl -H "x-cron-secret: $CRON_SECRET" https://ваш-сайт/api/cron/reminders
```

## Переменные окружения

| Переменная | Назначение |
| --- | --- |
| `DATABASE_URL` | Путь к SQLite, по умолчанию `file:./prisma/dev.db` |
| `ADMIN_PASSWORD` | Пароль входа в `/admin` (или `ADMIN_PASSWORD_HASH`) |
| `ADMIN_PASSWORD_HASH` | bcrypt-хеш пароля (`npm run hash-password`) — приоритетнее |
| `NEXT_PUBLIC_SITE_URL` | Публичный адрес сайта (для ссылок в письмах) |
| `YOOKASSA_SHOP_ID` | ID магазина ЮKassa |
| `YOOKASSA_SECRET_KEY` | Секретный ключ ЮKassa |
| `TG_BOT_TOKEN` | Токен бота Telegram для уведомлений админу |
| `TG_CHAT_ID` | Chat ID администратора |
| `SMTP_HOST` / `SMTP_PORT` | SMTP-сервер для писем (587 или 465) |
| `SMTP_USER` / `SMTP_PASS` | Учётка SMTP (пароль приложения) |
| `SMTP_FROM` | Адрес отправителя (по умолчанию `SMTP_USER`) |
| `CRON_SECRET` | Секрет cron-роута напоминаний |

Вебхук ЮKassa: `POST /api/webhooks/yookassa` — `payment.succeeded`
(запись → CONFIRMED + PAID, сохраняется `paymentId`) и `payment.canceled`.

## Структура

```
src/
  app/
    (marketing)/        — лендинг (отзывы, FAQ), врачи, услуги, контакты, документы
    (auth)/login/       — вход администратора
    admin/              — CRM: дашборд, ручная запись, расписания, услуги, отзывы
    book/               — онлайн-запись + страница успеха
    booking/[token]/    — управление записью по ссылке (отмена/перенос)
    api/slots/          — расчёт свободных слотов (врач опционален)
    api/payments/       — создание платежа ЮKassa
    api/webhooks/       — вебхук ЮKassa (IP-фильтр, идемпотентность)
    api/cron/reminders/ — напоминания за 24 часа (секрет в заголовке)
    api/admin/          — CSV-экспорт записей (проверка админ-сессии)
    opengraph-image.tsx — динамическая OG-картинка
    sitemap.ts, robots.ts
    actions.ts          — Server Actions (запись, отмена/перенос, админ-CRUD, отзывы)
  components/           — Header, Footer, CookieBanner, ReviewsSection, ReviewForm, StructuredData
  lib/                  — prisma, auth (HMAC-сессия), slots, tokens, notify, ratelimit
  proxy.ts              — защита роутов /admin (Next.js 16 proxy)
prisma/
  schema.prisma         — Doctor, Schedule, Service, Booking, BookingToken, Review, ProcessedEvent, User
  seed.mjs              — демо-данные
.github/workflows/ci.yml — CI: lint + build + smoke-тест страниц
```
